# WorkBuddy 请求安全边界

本功能用于减少错误重试和重复操作，不是绕过上游风控，也不能保证非官方接入不被限制。
国内版和国际版独立处理；账号的“启用”仍只控制推理转发，安全暂停是另一项状态。

## 错误处理

| 情况 | 本次请求 | 后续请求 |
| --- | --- | --- |
| 明确账号限制 | 不重试、不换号，按身份保存安全暂停 | 推理和后台请求停止；凭据刷新、重启不会解除 |
| 渠道拒绝，例如 `11-128`/`11128` | 不重试、不换号，不改写提示词 | 不把账号标记为封禁 |
| 队列繁忙，例如 `6021` | 快速失败，不遍历账号池 | 不污染账号模型额度；客户端应稍后重试 |
| 真实模型额度限制，例如 `6004` | 保留原有额度处理 | WorkBuddy 冷却期间不再使用强塞兜底 |
| 活跃任务鉴权、限流或渠道拒绝 | 停止本轮后续步骤 | 只有明确账号限制才持久暂停 |

原始数字、字符串业务码保留给分类器；HTTP 200 内的已知业务错误同样处理。
明确渠道证据优先于含糊的 `request illegal`。普通认证失败、限流和未知错误不能
仅凭一句文案被视为永久封号。

账号配置的并发上限通过现有连接占位原子执行，取消和流结束释放占位。
`maxConcurrent=0` 仍表示无限；其他提供商的既有选路策略不变。

## 安全暂停与人工恢复

账号列表显示“安全暂停”。先在官方客户端核实账号恢复，再使用账号菜单中的恢复操作。
确认仅解除本地暂停，不表示上游已解封；下一次收到明确限制会再次暂停。

管理 API 沿用面板鉴权：

```text
GET  /api/accounts/{id}/workbuddy-safety
POST /api/accounts/{id}/workbuddy-safety/resume
```

恢复请求必须携带刚查询得到的 `identity`、`revision` 和 `confirmed:true`。
身份或版本变化返回 409，不能用旧确认覆盖新限制。环境默认会话使用
`workbuddy` 或 `workbuddy-intl` 作为管理 ID，身份与实际发送会话一致。
数据库不可用或状态损坏时停止发送，不能当作“未暂停”。

暂停状态位于独立受保护的 SQLite KV 空间，不通过通用配置接口读写。
没有增加表、列或 schema 版本；不要手工删除 KV 来代替正常恢复。

## 国际网页活跃生命周期

按地区、UID、企业身份持久记录任务。创建会话前保存意图，收到会话 ID 后立即保存，
再进入沙箱/ACP。只有实际非空输出、正常 `end_turn` 和控制台 `completed`
同时满足才记成功；HTTP 200/202、连接建立或奖励查询成功不能替代这些证据。

- 同一 UTC 日已成功时直接复用成功结果，不再次创建会话。UTC 日只是本地去重窗口，
  不宣称与上游奖励结算时区一致。
- 活跃成功与奖励到账分开记录；活跃成功不能冒充领取或余额增加。
- 明确未创建的拒绝可以按原退避规则后续重试。
- 创建结果未知或已有会话但未确认完成时保留记录并停止自动新建，包括跨日和重启。
  这类情况需人工核对原会话；本轮不提供自动清除未知状态或猜测式重建。
- 不删除用户会话，也不调用未经验证的会话清理接口。

## 旧成长入口

旧任务、学校和旅行 API 保留功能及响应形状，与新成长入口共享同一个身份租约。
接受写操作前记录 `legacyPending`；请求断线不取消已接受的操作，未知结果不自动重放。
学校批次的抽奖子结果失败同样保留待核实状态，不能仅因任务列表成功就清除记录。
旧的任意 HTTP 400 跨域再次领取、buddy5 拒绝后补发另一形状事件不再执行；
目前没有经核实的兼容错误白名单，不能把未知拒绝当作可重试信号。

待核实时，成长面板离线显示本地记录，不依赖上游状态接口成功。确认官方端结果后，
使用“核对旧操作结果”入口；对应 API 为：

```text
POST /api/accounts/{id}/growth/legacy/resolve
```

请求携带 `confirmed:true`、`expectedIdentity` 和待核实记录的 `clientToken`。
该操作只确认本地记录，不调用、补发或重放上游业务。解除后仍须重新查询真实状态，
再由用户决定下一步。若账号同时安全暂停，应先核实并恢复账号。

## 验收边界

离线回归覆盖真实错误读取、分类与发送链、暂停持久化与恢复竞争、原子并发、
活动各阶段调用次数、网页创建状态、旧成长互斥及刷新取消释放。
前端使用生产构建和浏览器交互验证。上线只做最小正常业务请求，不为验收主动制造
封号、刷奖励、轮换身份或对受限账号反复探测。
